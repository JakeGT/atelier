# Interface audit, 2026-10-10

Part of the [interface design reference](README.md). The first full audit,
prompted by the owner being unable to find the Unpublish button.

**Method:** every screen was captured from a running copy of the app (public
page, sign-in, websites page, the five settings tabs, the editor with each side
tab, every dialog), then checked against the [review checklist](06-review-checklist.md).

## What was found and fixed

### Controls without words ([01](01-words-on-controls.md))

| Where | Was | Now |
| --- | --- | --- |
| Editor bar | Icon-only arrow, globe, sliders, panel, moon | **Websites**, **Address**, **Settings**, **Versions and wording**; theme switch in the account menu, in words |
| Composer | An arrow in a circle | **Send ↑** |
| Preview | Icon-only device sizes, reload, open | **Desktop / Tablet / Phone**, **Reload**, **Open** |
| Website cards | Three dots | **⋯ More** |
| Domains, providers, members | Bin and ✕ icons | **Remove**, **Check again**, **Disconnect**, **Remove** |
| Public pages | A moon icon | **Night** / **Day** |
| Studio navigation | "Studio" beside a gear | **Studio settings** |

### Actions that were hard to find ([02](02-finding-things.md))

| Where | Was | Now |
| --- | --- | --- |
| Unpublish | At the bottom of a dialog behind the globe icon | On the **Live** status menu, on each website card's **More** menu, and in the Address dialog |
| The live address | A small link | In the Live status menu with **Open** and **Copy**, and a dialog after every publish |
| Website cards | No sign of whether a website was public | **Live** or **Not published** on every card |
| Side panel tabs | Three unexplained lists | Each starts with a line saying what it is and what you can do |
| Studio switcher | A bare name with chevrons | Labelled **Studio**; the menu is titled "Switch studio" |
| Phone-width editor | Address and Settings became bare icons | Moved into the account menu, in words |
| Starter ideas on the websites page | Unlabelled chips | "Or start from an idea:" |
| Settings page title | "The studio." | "Studio settings." |

### Language only we understood ([03](03-plain-language.md))

| Where | Was | Now |
| --- | --- | --- |
| Versions, releases, the publish dialog | Commit hashes (`3b31b15`) | Removed; time and description only |
| Release states | `planned`, `failed`, `superseded` | "Not published", "Didn't publish", "Was live" |
| Side tabs | Versions / Releases / Content | Versions / **Published** / **Wording** |
| Wording editor | `rev 3`, "page · 3 fields", "Save draft", "Draft" | "Last changed …", "3 pieces of wording", "Save", "Not published yet" |
| Lists in wording (opening hours) | Edited as JSON with brackets and quotes | One per line |
| Publish dialog | "Design 3b31b15 · changed", "Replaces nothing (first release)" | "Pages and design: Changed", "Wording: 1 change", "Public right now: Nothing yet" |
| Version and release buttons | "Restore", "Roll back to this" | "Go back to this", "Put this one back" |
| Studio address | `/o/local-developer-…` | The full link, described as "Link to this studio" |
| Preview bar | The website's slug | "Preview · private" |
| Activity | "Prepared a release", "Rolled back" | "Started publishing", "Put an earlier release back"; unpublish, domains and providers now have entries too |
| Usage | "tokens" unexplained | One sentence saying what a token is |
| Models | "providers" and "keys" assumed | One sentence saying what a provider is and how connecting works |
| Model settings | "Automatic", "Studio default" | "The built-in model", "Studio default (name of the model)" |

### Missing explanations and silent states ([04](04-states-and-consequences.md))

| Where | Was | Now |
| --- | --- | --- |
| Leave studio (only owner) | A greyed-out button; the reason in a tooltip | The reason in place of the button |
| Member roles | Meanings in tooltips | Listed on the page |
| Archive | A button with a tooltip | A sentence beside it: what archiving does, what it does not, and where deleting is |
| Unknown addresses on a published site | Showed the home page | A "Page not found" page |

## Known and left as they are

| Item | Why |
| --- | --- |
| Wording field names come from what the assistant called them ("Hero title") | They are the assistant's keys. Fixing it properly means asking the assistant for a plain label with each field; noted for the content editor phase (P5) |
| ✕ in the model search box, ← on a phone-width editor bar, the avatar | On the [allowed list](01-words-on-controls.md#allowed-exceptions), with reasons |
| "Release 3" keeps the word "release" | It is the name of a numbered publish and reads naturally; "releases" as a tab became "Published" |
| The public landing page was only checked for controls, not re-written | Its copy is marketing, reviewed separately |
